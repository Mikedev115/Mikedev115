## Aetox harness

Any provider's model — the one you already pay for, or one running on your own machine — and the harness layer is
tuned to work with each of them.

The assistant side remembers the work we have done, on a token-management architecture of our own design.

The code mode does real work, it is measured in numbers that compare, and it runs in production.

[The site](https://mikedev115.github.io/Aetox-landing/) · [the repository](https://github.com/Mikedev115/Aetox-Harness) · [what's new](https://github.com/Mikedev115/Aetox-Harness/releases)

## Before that, and beside it

- **AI-Robot-Guide** — a tour-guide robot for Nan that took a national gold medal; it runs on the web, LINE OA and
  the robot itself, on two brains (Gemini for depth, Llama for speed) over Qdrant, MongoDB and Redis. I led the
  system architecture and built the core system.
- **BookMind** — took a traditional RAG pipeline and made it agentic: HyDE query rewriting, hybrid dense + BM25
  search, adaptive reranking, live web search and sentence-level compression, rebuilt into separate API, service,
  retrieval and agentic layers.

## How I work

I use Aetox harness as the assistant beside me — but the architecture, the plan and the scope are mine.
The code itself I have AI write, plainly, without pretending otherwise.

I check the result with my own eyes, closely, because the work is real.
A good system can be measured in numbers that compare; it does not need to be sold with words.
